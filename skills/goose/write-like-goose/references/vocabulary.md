# Vocabulary — Tier 1 replacements

Always replace these when used as AI filler (not when the literal/technical sense is required). Adapted from avoid-ai-writing (MIT).

| Replace | With |
|---------|------|
| delve / delve into | explore, dig into, look at |
| landscape (metaphor) | field, space, industry |
| tapestry | describe the actual complexity |
| realm | area, field, domain |
| paradigm | model, approach, framework |
| embark | start, begin |
| testament to | shows, proves |
| robust | strong, reliable, solid |
| comprehensive | thorough, complete, full |
| cutting-edge | latest, newest |
| leverage (verb) | use |
| pivotal | important, key |
| underscores | shows, highlights |
| meticulous / meticulously | careful, detailed |
| seamless / seamlessly | smooth, without friction |
| game-changer / game-changing | say what changed |
| utilize | use |
| watershed moment | turning point, or say what changed |
| marking a pivotal moment | state what happened |
| the future looks bright | cut or be specific |
| only time will tell | cut or be specific |
| nestled | is in, sits in |
| vibrant | say what makes it active, or cut |
| thriving | growing, active, or cite a number |
| showcasing | showing, or cut the clause |
| deep dive / dive into | look at, examine |
| unpack / unpacking | explain, break down |
| intricate / intricacies | complex, or name the complexity |
| ever-evolving | changing, or say how |
| enduring | lasting, or cite duration |
| daunting | hard, difficult |
| holistic / holistically | complete, or say what's included |
| actionable | practical, concrete |
| impactful | effective, or describe the impact |
| learnings | lessons, findings |
| thought leader / thought leadership | expert, or their real contribution |
| best practices | what works, proven methods |
| at its core | cut; state the thing |
| synergy / synergies | describe the combined effect |
| interplay | relationship, interaction |
| in order to | to |
| due to the fact that | because |
| serves as | is |
| features (verb, inflated) | has, includes |
| boasts | has |
| commence | start |
| ascertain | find out, determine |
| endeavor | effort, try |
| embrace (metaphor) | adopt, use |
| foster / fostering | support, help, build |
| align with | match, fit |
| additionally (as glue) | also, or restructure |

**Keep when technical/literal:** e.g. `deeply nested`, `exactly-once`, `robust` as in statistics, `leverage` in finance, `landscape` as UI mode.

**Empty intensifiers (cut):** genuinely / truly / quite frankly / really / simply / actually when they add no information. Keep when they mark real uncertainty or a needed distinction.
