# Phrases and structures to cut

Adapted from stop-slop (MIT). Use with [`patterns.md`](patterns.md).

## Throat-clearing openers

Cut and state the point:

- Here's the thing / Here's what / Here's why
- The uncomfortable truth is / It turns out / The real X is
- Let me be clear / The truth is / I'll say it again
- I'm going to be honest / Can we talk about
- Here's what I find interesting / Here's the problem though

## Emphasis crutches

Delete: Full stop. / Period. / Let that sink in. / This matters because / Make no mistake / Here's why that matters

## Business jargon

Word-level swaps (`landscape`, `unpack`, `deep dive`, `leverage`, `utilize`, …) live in [vocabulary.md](vocabulary.md) — that is the single source for those. This table covers **phrase-level** jargon vocabulary.md does not:

| Avoid | Prefer |
|-------|--------|
| Navigate (challenges) | Handle, address |
| Lean into | Accept, do |
| Double down | Commit, increase |
| Take a step back | Reconsider |
| Moving forward | Next |
| Circle back | Return to |
| On the same page | Agreed |

## Empty adverbs / hedges

**Not** "kill every adverb." Technical writing needs some (`exactly`, `deeply nested`, `only`). Cut **empty** ones: really, just, literally, genuinely, honestly, simply, actually, truly, fundamentally, inherently, inevitably, interestingly, importantly, crucially (when they add no information).

Also: At its core / In today's X / It's worth noting / At the end of the day / When it comes to / In a world where / The reality is

Keep a hedge when it carries real uncertainty (deleting it would invent false confidence).

## Meta-commentary

Cut: Hint: / Plot twist: / You already know this, but / But that's another post / X is a feature, not a bug / The rest of this essay… / Let me walk you through… / In this section, we'll… / As we'll see… / I want to explore…

## Vague declaratives

Kill or replace with the specific thing:

- The reasons are structural
- The implications are significant
- The stakes are high
- The consequences are real

## Binary contrasts

State Y directly. Drop the negation runway.

| Pattern |
|---------|
| Not because X. Because Y. |
| X isn't the problem. Y is. |
| The answer isn't X. It's Y. |
| It feels like X. It's actually Y. |
| Not X, it's Y / not just X but also Y |

## Negative listing

"Not A. Not B. C." → just state C.

## Dramatic fragmentation

"[Noun]. That's it." / "X. And Y. And Z." → complete sentences; don't stack punchy fragments.

## Rhetorical setups

What if…? / Here's what I mean: / Think about it: / And that's okay. → make the point.

## False agency

Name the actor:

| Bad | Better |
|-----|--------|
| the decision emerges | someone decided |
| the data tells us | we read the data and concluded |
| the market rewards | buyers pay for |
| a complaint becomes a fix | the team fixed it |

## Narrator-from-a-distance

"Nobody designed this" / "People tend to…" → put the reader in the seat when it fits ("You don't sit down and decide…"), or name who.

## Passive voice

Prefer a subject doing something when it clarifies. "X was created" → who created it.

## Rhythm

- Vary sentence length under the STE caps (rule lives in [ste100.md](ste100.md))
- Prefer two items over padded threes
- Vary paragraph endings (not every line a punchline)
- No em/en dashes
- Lazy extremes (every / always / never) only with real warrant
