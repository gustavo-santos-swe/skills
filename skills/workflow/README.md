# workflow

Do problema ao PR: spec, plano, execução, documentação colaborativa, ship.

| Skill | Uso |
|-------|-----|
| `brainstorming` | Design antes de código |
| `writing-plans` | Plano de implementação |
| `executing-plans` | Executar task por task |
| `doc-coauthoring` | Specs, RFCs, PRDs |
| `ship-feature` | Commit + push + PR |
